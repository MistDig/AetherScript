# AetherScript visual identity

The field guide uses midnight navy (#102B4B), sky (#EAF6FF), warm ivory (#FFFDF8), lavender (#F0EAFF), and periwinkle (#6881C5). Typography uses system Segoe UI/Arial for portable SVG rendering. Keep text dark, whitespace generous, and the cloud playful but uncluttered. The mascot has no gameplay or security meaning.

- `cloud-mascot.png`: original transparent image generated with OpenAI imagegen for this project; 1536 × 1024. No external brand reference or third-party illustration was supplied.
- `aetherscript-banner.svg`: code-authored accessible vector composition with the original mascot embedded, so rendering requires no external image request.
- `aetherscript-banner.png`: raster export of the code-authored SVG, rendered with resvg for portable GitHub display; inspected locally without browser automation.
- Wiki Markdown lives in `docs/wiki/` and is mirrored to the GitHub wiki repository. GitHub controls page typography/layout; the banner and native Markdown work without custom CSS or JavaScript.

## Mascot generation prompt

Use case: logo-brand. Asset type: a premium friendly cloud mascot for the AetherScript open-source Minecraft scripting language documentation. Primary request: an extremely cute small puffy white cloud with a tiny happy smile. Single centered mascot, full body visible with comfortable padding, genuine transparent background. A soft rounded cloud silhouette, 5 generous pillowy lobes, slightly warm ivory white body, gentle pale-periwinkle shading underneath, two small dark midnight-blue oval eyes set wide apart, one tiny curved smile and subtle rosy blush cheeks. Minimal expressive face, no arms, no legs, no accessories, no surrounding objects, no text or letters. Polished 2.5D clay-like illustration with clean readable silhouette and subtle velvety lighting, adorable but refined rather than generic clip art. Designed to remain clear at 64 pixels and look beautiful at larger sizes. No photoreal sky, no checkerboard backdrop, no border, no watermark, no heavy shadow outside the silhouette.
